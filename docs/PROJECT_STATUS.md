# 项目状态与评测边界

状态整理日期：2026-10-03。此文件是面向源码读者的摘要，不是原始实验报告，也不替代数据、预测及产物完整性证据。

## 当前产品默认

保留已有 RF / ET / RGB TCN 融合及 decoder：

```text
corrected_motion_rf  0.4
corrected_motion_et  0.4
rgb_motion_tcn      0.2
```

树分支结合校正 JEPA 与运动，TCN 分支结合 RGB 与运动。未同时满足定位、误报、空候选和推理兼容护栏的研究分支没有替换默认。当前默认不是历史实验所有单项指标的最高值。

## 固定默认控制的开发集折外结果

数据规模为 77 条视频、76 个内容 SHA 组、6133 帧、85 个异常事件；14 正常/63 异常。同内容视频按组隔离，既有少量重复内容标签冲突没有为提高成绩而改写。

| 指标 | 结果 |

| F1 @ IoU 0.3 | 55.71% |

| Frame F1 | 50.89% |

| 异常视频无候选 | 22/63 |

该数据集已经多轮探索，不是新盲测。事件定位 F1、Frame F1、视频级误报计数不能互称“准确率”，也不能直接与历史 in-sample、其他数据集或不同门控方案的指标混排。

## 最新局部交互方向

最近一轮先做了预先固定的容量诊断，保留默认模型不动。局部强度变化在部分低证据事件上有诊断信号，但没有第二个独立基本特征 family 同时通过对应目标的准入要求。因此停止该路线的进一步训练；没有训练并上线新定位头，没有证明产品指标提升。

JEPA 中心裁剪空间覆盖、稀疏时序支持和 tubelet 混合边界仍是限制。这些观察不能单独证明漏检的因果机制。新的相似场景正常/异常配对数据尚未完成采集，不能称已经通过外部测试。
